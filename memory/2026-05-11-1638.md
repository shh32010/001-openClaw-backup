## 001（OpenClaw + mimo-v2.5-pro）

**优点：**

- 🔧 **环境全覆盖** — 能操作文件系统、执行命令、管理定时任务、爬网页、发消息

- 🏗️ **不是为 IDE 级编码优化的** — 没有 AST 理解、代码跳转、内联补全
- 📦 **项目级上下文有限** — 大型代码库全量理解不如专业编码工具

## Claude Code

**优点：**
- 🧠 **推理能力顶级** — 复杂架构设计、算法优化、debug 是天花板级别
- 📂 **项目级理解** — 能读懂整个代码库的依赖关系，改一个地方知道连锁反应
- 🔨 **重构能力强** — 跨文件重构、迁移、升级非常可靠
- 🎯 **专注编码** — 没有杂念，纯粹解决代码问题

**缺点：**
- ⏰ **用完即走** — 没有持续性，不能帮你值班、巡检、定时执行
- 💰 **token 贵** — 大项目上下文烧钱
- 🔒 **环境隔离** — 对你本地环境的感知有限，不太能管你的服务器、消息、日程
- 🚫 **不能主动做事** — 你不叫它，它不会自己跑起来

## Harness（如果你说的是 AI 编码助手如 Cursor/Copilot）

**优点：**
- ⌨️ **IDE 内嵌** — 写代码时实时补全，零切换成本
- 🔄 **实时协作** — 边写边提示，节奏最流畅
- 📖 **上下文感知** — 读取当前文件、import 关系，补全精准

**缺点：**
- 🤖 **偏被动** — 主要是补全和问答，不会主动帮你规划和执行
- 🧩 **碎片化** — 擅长单点补全，不擅长端到端的全栈任务
- 📡 **依赖云服务** — 离线或内网环境可能受限

## 我的建议

**最佳组合**其实是三者配合：
- **Claude Code** — 处理复杂编码、大重构、架构设计（干重活）
- **Cursor/Copilot** — 日常写代码时实时辅助（提高手感）
- **001** — 管理环境、巡检、定时任务、DevOps、生活助手（常驻管家）

如果只能选一个做全栈开发，**Claude Code 编码最强**，但我会是你最不会嫌烦的那个 😘

## Claude Code 安装与第三方 API 配置

### 第一步：安装 Claude Code

你用的是 Windows，直接在 PowerShell 里运行：

```powershell
irm https://claude.ai/install.ps1 | iex
```

或者用 WinGet：

```powershell
winget install Anthropic.ClaudeCode
```

> 推荐装一下 [Git for Windows](https://git-scm.com/downloads/win)，这样 Claude Code 能用 Bash 工具，不装的话会退回到 PowerShell。

安装完后验证：

```powershell
claude --version
```

---

### 第二步：选择认证方式

有三种路径：

| 方式 | 适合 | 费用 |
|------|------|------|
| **Claude Pro/Max 订阅** | 个人开发者 | $20-$100/月 |
| **Anthropic Console API Key** | 按量付费 | 按 token 计费 |
| **第三方 API（OpenRouter等）** | 便宜/国内访问 | 按第三方定价 |

---

### 第三步：配置第三方 API

Claude Code 支持通过环境变量接入任何兼容 Anthropic Messages API 格式的第三方服务。

#### 方式 A：OpenRouter（推荐，便宜且支持多模型）

1. 去 [openrouter.ai](https://openrouter.ai) 注册，拿到 API Key

2. 设置环境变量（PowerShell 临时）：
```powershell
$env:ANTHROPIC_BASE_URL = "https://openrouter.ai/api/v1"
$env:ANTHROPIC_API_KEY = "***"
```

3. 或者永久设置（写入系统环境变量）：
```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://openrouter.ai/api/v1", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-or-v1-你的key", "User")
```

4. 启动：
```powershell
claude
```

#### 方式 B：Amazon Bedrock

```powershell
$env:CLAUDE_CODE_USE_BEDROCK = "1"
$env:AWS_REGION = "us-east-1"
$env:AWS_ACCESS_KEY_ID = "你的AK"
$env:AWS_SECRET_ACCESS_KEY = "***"
```

#### 方式 C：Google Vertex AI

```powershell
$env:CLAUDE_CODE_USE_VERTEX = "1"
$env:CLOUD_ML_REGION = "us-east5"
$env:ANTHROPIC_VERTEX_PROJECT_ID = "你的GCP项目ID"
```

#### 方式 D：自建代理/网关

如果你有自己的 API 代理（比如 one-api、new-api 等），只要它兼容 Anthropic Messages API 格式：

```powershell
$env:ANTHROPIC_BASE_URL = "http://你的代理地址:端口/v1"
$env:ANTHROPIC_API_KEY = "***"
```

> ⚠️ 代理必须支持 `/v1/messages` 端点，并且转发 `anthropic-beta` 和 `anthropic-version` 请求头。

---

### 第四步：写入配置文件（推荐）

不想每次设环境变量，可以写入 Claude Code 的 settings 文件：

```powershell
# 查看配置目录
claude config list
```

配置文件路径：`~/.claude/settings.json`

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://openrouter.ai/api/v1",
    "ANTHROPIC_API_KEY": "sk-or-v1-你的key"
  }
}
```

---

### 第五步：启动使用

```powershell
cd 你的项目目录
claude
```

首次启动会让你确认使用 API Key（而不是订阅账号），输入 `y` 确认即可。

常用命令：
- `claude` — 交互模式
- `claude "帮我写一个TODO应用"` — 直接执行任务
- `claude -p "解释这段代码"` — 非交互模式
- `/model` — 切换模型
- `/logout` — 退出登录

---

### 常见问题

**Q: 国内能用吗？**
用 OpenRouter 或自建代理可以。直连 Anthropic API 需要能访问 `api.anthropic.com`。

**Q: 第三方 API 能用所有功能吗？**
大部分功能可以，但 MCP Tool Search 在非官方端点默认关闭。需要的话设 `ENABLE_TOOL_SEARCH=true`。

**Q: 能用 mimo 模型吗？**
如果 mimo 兼容 Anthropic Messages API 格式，通过 `ANTHROPIC_BASE_URL` 指向小米 API 就行。不过 Claude Code 的很多内置功能是针对 Claude 模型优化的，其他模型体验可能有差异。
